軽量メモツール v1
========================================

このZIPには、ツール本体のファイル一式が入っています。

「解凍して index.html をダブルクリック」では正しく動きません。
（スマートフォンでは使えず、PCでもメモが保存できないことがあります）

最初に一度だけ、下の手順でWeb上に置いてください。
置いたあとは、オフラインでも使えます。


■ 置く（最初に1回だけ／PCで行います）
----------------------------------------
GitHub Pages を使う場合：

 1. GitHub でリポジトリを新規作成する（Public）
 2. このZIPを解凍し、中のファイルとフォルダを
    すべてリポジトリ直下へアップロードする
    （index.html がリポジトリの一番上に来るようにする）
 3. Settings → Pages → Branch: main /(root) → Save
 4. 数分待つと
    https://＜ユーザー名＞.github.io/＜リポジトリ名＞/
    で開けるようになる

Netlify Drop（https://app.netlify.com/drop）に
解凍したフォルダをドラッグしても構いません。

どちらも無料で、サーバー側の準備は一切不要です。
このURLを友人に渡してください。


■ 使う（スマートフォン）
----------------------------------------
 1. 渡されたURLをブラウザで開く
 2. ホーム画面に追加する
     ・iPhone（Safari）  : 共有ボタン →［ホーム画面に追加］
     ・Android（Chrome） : 右上メニュー →［ホーム画面に追加］
 3. 以後はアイコンから起動する。機内モードでも使えます。

PC（Chrome / Edge）の場合は、アドレスバー右の
インストールアイコンから追加できます。


■ 大事なこと
----------------------------------------
・メモはその端末の中だけに保存されます。
  クラウド同期はしません。アカウントもログインもありません。
・機種変更の前、ブラウザのサイトデータを消す前には、必ず
  設定 →［全データをバックアップ］でファイルを保存してください。
  戻すときは 設定 →［バックアップから復元］です。
・書き出したファイルは端末の「ダウンロード」等に保存されます。
  共有画面やクラウドは自動で開きません。自分で移動してください。


■ 入っているもの
----------------------------------------
  index.html              本体
  manifest.webmanifest    ホーム画面追加用の情報
  sw.js                   オフライン用
  css/  js/  icons/       スタイル・プログラム・アイコン

外部のライブラリ、ビルド作業、サーバー処理はありません。
