# メモ

スマートフォンのホーム画面から開く、軽量なメモツールです。

- オフラインで動きます
- アカウント・ログイン・クラウド同期はありません
- データは使っている端末の中だけに保存されます
- 外部のライブラリ、ビルド作業、サーバー処理は一切ありません

---

## 公開する手順（最初に1回だけ）

1. このリポジトリの **Settings** を開く
2. 左メニューの **Pages** を選ぶ
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 数分待つと、次のURLで開けるようになります

```
https://＜ユーザー名＞.github.io/＜リポジトリ名＞/
```

このURLを、使う人に渡してください。

> **注意**
> `index.html` がリポジトリの**一番上の階層**にある必要があります。
> フォルダの中に入れてしまうと、その分だけURLが長くなります。

---

## 使う人の手順

1. 渡されたURLをブラウザで開く
2. ホーム画面に追加する
   - iPhone（Safari）: 共有ボタン → ［ホーム画面に追加］
   - Android（Chrome）: 右上メニュー → ［ホーム画面に追加］
   - PC（Chrome / Edge）: アドレスバー右のインストールアイコン
3. 以後はアイコンから起動します。機内モードでも使えます

アプリの使い方は、**メモ一覧 右上の ⚙️ → ［使い方をみる］** に入っています。

---

## 更新する手順

新しいファイルを**同じリポジトリに上げ直すだけ**です。
保存されているメモは消えません。上げ直したあと、アプリを開き直してください。

ただし、リポジトリ名やユーザー名を変えるとURLが変わり、
**別のアプリとして扱われるため、前のメモは引き継がれません。**
引っ越す場合は、旧URLで［全データをバックアップ］→ 新URLで［バックアップから復元］
の順に移してください。

---

## データについて（重要）

メモ・画像・タグ・設定は、使っている端末のブラウザ内だけに保存されます。
このリポジトリや、どこかのサーバーには送信されません。

次の場合はデータが消えます。

- URL（公開先）が変わったとき
- ブラウザの「サイトデータを削除」を実行したとき
- ホーム画面のアイコンを削除したとき（端末による）
- プライベートブラウズで使ったとき

**機種変更の前やブラウザのデータを消す前には、必ず
［設定］→［全データをバックアップ］でファイルを保存してください。**

```
index.html              本体
manifest.webmanifest    ホーム画面に追加するための情報
sw.js                   オフライン用（Service Worker）
css/app.css             見た目
js/                     プログラム
icons/                  アイコン
```
